# Medical Insurance Cost Prediction Using Machine Learning

## Project Overview
This project predicts medical insurance costs based on individual details using Machine Learning regression algorithms.

## Dataset
Medical Cost Personal Dataset from Kaggle.

Dataset link:
https://www.kaggle.com/datasets/mirichoi0218/insurance

## Input Features
- Age
- Gender
- BMI
- Number of Children
- Smoking Status
- Region

## Target Variable
- Insurance Charges

## Machine Learning Algorithms
1. Linear Regression
2. Decision Tree Regression
3. Random Forest Regression

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Model Evaluation
The models are evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Output
The trained model predicts estimated medical insurance costs for new individuals.
